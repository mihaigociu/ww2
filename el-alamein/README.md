# El-Alamein (1942)

This folder contains educational materials about the battles of El-Alamein and related topics, written for high-school students (ages 14–18).

## Documents

| File | Description |
|------|-------------|
| [el-alamein.md](el-alamein.md) | Main document — the two battles of El-Alamein (July and October–November 1942): background, commanders, battle phases, casualties, Commonwealth contributions, and historical significance |
| [discussion-guide.md](discussion-guide.md) | A teacher and student guide to the eight discussion questions in the main document, with key ideas, hints, things to avoid, and pointers to strong answers |
| [saint-minas-miracle.md](saint-minas-miracle.md) | The Greek Orthodox and Coptic tradition of Saint Minas's miraculous apparition at El-Alamein — covering the saint's biography, the Abu Mena shrine, the Greek Brigade's role, and how to read a story that bridges religious tradition and secular history |
| [RESEARCH_PLAN.md](RESEARCH_PLAN.md) | The research methodology and source plan used to produce the main El-Alamein document |

## Reading Order

For students new to the topic, the recommended reading order is:

1. **[el-alamein.md](el-alamein.md)** — start here for the full historical picture
2. **[saint-minas-miracle.md](saint-minas-miracle.md)** — explore the religious tradition connected to the battle
3. **[discussion-guide.md](discussion-guide.md)** — use this alongside either document for classroom discussion or independent study

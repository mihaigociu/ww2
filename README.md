# World War II — Educational Materials

A collection of educational documents about World War II, written for high-school students (ages 14–18).

Each document covers a significant battle or event, with maps, cited sources, a glossary, and classroom discussion questions.

## Contents

| Topic | Document | Description |
|-------|----------|-------------|
| Battle of El-Alamein (1942) | [el-alamein/el-alamein.md](el-alamein/el-alamein.md) | The two battles of El-Alamein — Rommel vs. Montgomery in the North African desert |
| El-Alamein: Discussion Guide | [el-alamein/discussion-guide.md](el-alamein/discussion-guide.md) | Hints and directions for each discussion question in the main El-Alamein document |
| The Miracle of Saint Minas (1942) | [el-alamein/saint-minas-miracle.md](el-alamein/saint-minas-miracle.md) | The religious tradition of Saint Minas's apparition at El-Alamein — history, faith, and legacy |

## Structure

Each topic folder contains:
- A **research plan** outlining sources and methodology
- The **educational document** in Markdown format
